# libretro shaders (subset)

Copied unmodified from the libretro `glsl-shaders` collection (as installed by RetroArch, `shaders_glsl`).
License and authorship are in the header of each `.glsl` file (FSR: MIT port; ScaleFX: Sergio Garcia / Hyllian; super-xBR: Hyllian; jinc2: Hyllian/Hans-Kristian; FXAA: Timothy Lottes; xBRZ: Zenju / Hyllian).

Included: `fsr/` (EASU + RCAS), `scalefx/`, `xbr/` (super-xBR passes + jinc2), `anti-aliasing/` (FXAA), `xbrz/` (freescale).
Any other RetroArch GLSL preset (`.glslp`) can be loaded by path: `--shader-preset C:\path\to\preset.glslp`.
